# Talking Stick 0.15.0

Date: 2026-09-15

## Added

- **`tt chat` operator console.** Talk with agents from any harness in one full-screen terminal conversation. Messages have readable sender labels, timestamps, and consistent harness colors. The input and compact room-status footer stay fixed at the bottom while the conversation scrolls.
- **Chat controls.** Broadcast plain text or address every matching `@agent` prefix, including `@codex, hello`. Type `/` for commands and Tab for completion. Mouse wheel, Page Up/Down, and Shift+Up/Down scroll history; Ctrl+End or `/bottom` returns live. New arrivals preserve the older view and show an unread count. Use `--no-mouse` for keyboard-only scrolling.
- **Safe draft editing and exit.** Multiline paste stays in the draft until Enter. Ctrl+C and Escape clear without quitting; `/quit`, `/exit`, or Ctrl+D on an empty draft exits and restores the previous terminal screen. A room closing prints an explanation after restoration. Recent history defaults to 20 entries (`--history 0` disables it), and turn details are optional with `--events`.
- **Independent operator consoles.** Every chat console has a unique `human_chat` observer identity. Observers can read and send room-visible messages without acquiring the stick, receiving handoffs, affecting solo detection, keeping abandoned rooms alive, or emitting join/leave wakes.

## Changed

- **Solo waits listen instead of claiming.** With no other turn-taking agent present, ordinary `tt wait` listens and prints a hint. Pass `--claim` to work alone. Assigned turns remain claimable normally. This prevents a listener-only harness from becoming trapped behind its own stop hook. (#68)

## Fixed

- **Completed self-events do not wake an agent again.** A wait suppresses the caller's completed release/pass and obsolete claim events before pagination. Audit history and takeover warnings remain available. (#68)
- **Linked worktrees find umbrella rooms.** Room resolution now checks ancestors of the main checkout as well as the worktree's own ancestors. Explicitly created per-worktree rooms still take precedence. (#68)
