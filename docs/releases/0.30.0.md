# Talking Stick 0.30.0

Date: 2026-10-22

## Added

- Host-wide `/rooms` navigator opens Folders first; Backspace raises its root beyond
  the current repository. Tab shows an Active room-only tree, with shared paths compressed
  and collapsed unread/member rollups. Search and name/path/activity/member sorting preserve
  the hierarchy; All open includes empty rooms. Explicit opening reanchors the local strip;
  browsing does not join rooms or refresh presence (#168, #171).
- `/clear` clears the chat pane and saves a per-human, per-room resume marker. Reopening
  starts after it; `/older` still retrieves the archive. Earlier pins are hidden without
  acknowledging them or changing agents' receive cursors (#166).
- A [harness control shim register](../harness-control-shims.md) tracks native API
  candidates and temporary terminal/hook fallbacks. Member context controls remain proposed.
- `tt install herdr` links a Herdr plugin and `tt chat-link` handler so a Ctrl-click on a pinned
  chat message acknowledges it without mouse capture (#160).
- Pending operator messages remain in their original timeline position while visible and pin
  only after newer output pushes them above the live transcript. The live transcript omits
  the pinned copy, and inline scrolling preserves message text in native scrollback with
  mouse capture off. Fullscreen manual traversal suppresses re-pinning without acknowledging,
  and inline chat in Herdr does the same when native scrollback is scrolled past a message (#162).

## Changed

- Pending operator messages no longer enable terminal-wide mouse capture automatically.
  Native scrolling and text selection work by default. Plain click acknowledgement now needs
  explicit `tt chat --mouse`; Herdr Ctrl-click (after `tt install herdr`) and `/ack` do not
  capture the mouse. `--no-mouse` is still supported.

## Fixed

- Earlier pinned messages share a continuous drawer background, including spacing, with one
  subtle “Earlier” label. Authored messages keep their normal formatting.
- Inline chat in Herdr buffers incoming output while browsing native scrollback, preserving
  the visible text and scroll position, then appending the complete buffered history on return.

## Upgrading and limits

Run `tt self-update`, then restart running `tt chat` consoles. Herdr users should also run
`tt install herdr` to install the native Ctrl-click link handler; self-update does not install
that plugin. `/ack` works without a plugin. Plain click acknowledgement requires `--mouse`,
which also captures wheel and drag input. `--no-mouse` remains supported.

`/rooms` opens Folders first. Tab switches to the Active room-only tree; `a` includes empty
rooms, `/` filters, and `s` changes sibling sorting. Backspace raises the folder root, so the
navigator can reach other repositories. `/clear` saves only this human's view marker in this
room; `/older` can retrieve the archive. It never resets member context or acknowledges pins.

Native manual-scroll traversal detection is specific to Herdr. In other terminals, messages
pin after newer output pushes them off the live pane; `/ack` remains portable. The operator
authorized this release on 2026-10-22; physical terminal acceptance of every latest path has
not been independently repeated. Automated xterm and service tests cover the changed paths.
Desktop push, remote harness context controls and Windows binaries are not included.
