# Talking Stick 0.36.0

Date: 2026-11-23

## Changed

- Harness sessions with OS access to the supervisor can run its commands, including `install`, `uninstall`, and `migrate`. Commands that change state still reject `--agent`. Claude workers can opt in to `bypassPermissions`, and Codex workers can opt in to `danger-full-access` and `never` approvals.
- The supervisor keeps the caller's executable search path on worker registration and service installation. Missing executables hold the worker immediately and show the cause in `tt supervisor status` and chat `/who`.
- Claude workers use the local username to locate the existing subscription login.

## Fixed

- Codex wake calls run without cmux session hook injection. Chat and health report queue failures, and an explicit hook-flag rejection is treated as unsent.

## Upgrading

- On macOS, if a worker uses the service's PATH and cannot find its harness, run `tt supervisor install` from a shell where the harness is on PATH, then `tt supervisor resume WORKER`. If the worker has a saved PATH or executable override, re-add it with a corrected path. See [Supervisor setup](../supervisor.md#permissions-and-environment).
- The Codex queue fix applies to the sender. A Codex thread the shared daemon reports as unloaded can still keep a message queued without starting a turn. See [#238](https://github.com/mostlydev/talking-stick/issues/238).
