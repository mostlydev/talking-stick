# Talking Stick 0.32.0

Date: 2026-10-24

## Breaking changes

- Without `--agents` or a saved choice, `tt up` starts Claude and Codex, when installed, instead
  of every default launcher. Antigravity, like Grok and OpenCode, now starts only when chosen.

## Added

- The first plain `tt up` in a terminal asks which agents to start and whether to remember the
  choice for every room or only this one (#183). `tt up --choose` asks again, and
  `tt up --agents a,b --save [--room]` saves without asking. Choices are kept in `launch.json`
  in the data directory. It never asks under `--json`, `--print`, a redirected terminal or an
  agent's shell. A saved agent that is no longer installed asks again in a terminal, and is
  otherwise skipped with a note, never replaced.

## Fixed

- While waiting for joins, `tt up` says when a member matches its pane's session and process
  but recorded no process start time, which it needs to prove the join, and names a Windows
  account that cannot inspect processes as one possible cause (#189). The wait, the proof and
  the unconfirmed result are unchanged, and a start recorded later still confirms.

- `tt up` starts independent Herdr agents concurrently after creating their panes,
  preserving each agent's startup and join checks. A slow or blocked neighbour no longer
  delays the next startup; layout stays ordered and no uncertain call is retried (#182).

- `tt up` recovers from an inherited `TT_ROOM` naming a closed or deleted room by
  selecting the room for the launch directory. Explicit `--in` selectors, ambiguous
  inherited names and storage errors still fail rather than launching into another room (#176).

## Upgrading and limits

Run `tt self-update`, then restart running `tt chat` consoles and harnesses.
Windows and hand-extracted copies require a manual download from the release;
check the archive against `checksums.txt`, extract it and run `tt install --all`.

Use `tt up --choose` to change the saved harness selection. For scripts, use an
explicit `--agents` list when the exact set matters. Choices can be saved for
all rooms or overridden for a particular room; a global save clears the current
room's override while preserving overrides for other rooms.

The missing-start diagnostic does not shorten the join wait or relax identity
proof. Windows early exit still needs a positively identified member-side probe
failure (#189). Harness context controls remain deferred (#166); no compaction,
reset or desktop-push runtime is introduced in this release.

## Verification

Release-candidate checks passed: 1,167 Node tests (1 skipped), 7 Bun SQLite and
service tests, typecheck, build, help, diff and package checks. CI must pass on the release PR
and the merged commit before tagging. The tag workflow builds and rehearses all
five native targets, then publishes their archives with `checksums.txt`.

The parallel-start implementation was independently tested with deferred runners,
real child-process barriers and timeout/abort cleanup, including a compiled Bun
smoke. In an isolated Herdr 0.9.5 session, two fresh Claude readiness calls took
7.310 seconds serially and 3.827 seconds in parallel. This measured readiness,
not complete room joins; no prompts were sent. The picker was driven in a PTY
through selection, cancellation and resize. The operator's physical terminal
try-out is still pending.
