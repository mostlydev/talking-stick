# Talking Stick 0.33.1

Date: 2026-11-12

## Changed

- The room header labels the list of other rooms: `other rooms: #api 2 for you` instead of
  `#api 2@`, so it no longer reads as a topic. Narrow headers keep the compact form.

## Documentation

- The skill tells agents not to launch another harness as their counterpart, not to stop
  another member's process, and to reread room events before acting on an agreed plan.

## Fixed

- Unread-message review paging uses the visible body height, including after a terminal
  resize. Long messages no longer skip lines near the end in inline chat.
- In Herdr, scrolling up in inline chat hides the unread or review bar until you return to the
  bottom, so it no longer cuts through the text. Scrolling and selection stay native.
