# Talking Stick 0.37.0

Date: 2026-11-23

## Added

- Rooms keep up to three open blockers. See them in chat, `tt blocker list`, and `tt room brief`. An explicit resolution message closes a blocker and stays in room history, including when sent from outside an empty room.
- Chat prints one line when another member raises or withdraws a blocker in the current room, so a new decision request appears in the conversation as well as in the header count.

## Fixed

- A chat console left open past midnight no longer greys out the conversation it is showing. Only activity from before the day the console opened, or before the latest conversation break, is dimmed.
- Chat keeps supervised Claude visible after a reply by recognizing its version-named native process instead of attributing room activity to its temporary command shell.
